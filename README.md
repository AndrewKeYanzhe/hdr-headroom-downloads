# HDR Headroom for Android

Check the current HDR-to-SDR headroom reported by an Android display, and its maximum configured headroom where supported.

## Download

[Download the Android APK (v1.0.7)](https://github.com/AndrewKeYanzhe/hdr-headroom-downloads/releases/download/v1.0.7/HDR-Headroom-v1.0.7.apk)

[View releases and version notes](https://github.com/AndrewKeYanzhe/hdr-headroom-downloads/releases)

Open the APK on an Android phone and allow installation from the browser or file manager if prompted. Future releases signed with the same key can be installed as updates.

## About the readings

- Current headroom uses the display's live HDR-to-SDR ratio reporting.
- Maximum configured headroom is available on Android 16 and newer when reported by the device. It is a configured ceiling, rather than a guarantee at every brightness or ambient condition.
- Unsupported or unavailable readings appear as **Not reported**.

This repository distributes signed APK downloads and SHA-256 checksums. Display reporting depends on Android version and device support.
